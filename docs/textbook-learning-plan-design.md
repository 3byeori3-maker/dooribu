# 학교 지정 교과서 기반 학습계획 설계

## 제품 목표

학생이 다니는 학교의 지정 수학 교과서, 학교 진도, 시험 일정, 개인 이해도를 하나의 학습계획으로 연결한다. 사진 질문은 독립 기능이 아니라 현재 교과서 단원과 학습계획 안에서 발생한 학습 이벤트로 기록한다.

## 핵심 사용자 흐름

1. 학교 검색 및 학년·학기 선택
2. 학교 지정 교과서 자동 추천
3. 표지 또는 ISBN 촬영으로 출판사·저자·교육과정 확인
4. 시험일, 시험 범위, 주당 학습 가능 시간 입력
5. 간단한 진단으로 단원별 기초 이해도 확인
6. 교과서 진도와 취약 개념을 결합해 주간 계획 생성
7. 질문·풀이·오답 결과를 반영해 매일 계획 재조정

## 콘텐츠 계층

```text
교육과정
└─ 성취기준
   └─ 교과서
      └─ 대단원
         └─ 중단원
            └─ 차시·페이지
               ├─ 개념
               ├─ 예제
               ├─ 활동
               └─ 평가 문항
```

각 콘텐츠 조각은 `curriculum_version`, `grade`, `semester`, `publisher`, `isbn`, `unit_id`, `page_from`, `page_to`, `achievement_standard_id`, `license_scope`를 가진다.

## 주요 데이터 모델

- `schools`: 학교명, 지역, 학교 코드
- `textbooks`: 교육과정, 학년, 과목, 출판사, ISBN, 라이선스 범위
- `school_textbook_assignments`: 학교·학년도·학년·과목별 지정 교과서와 확인 상태
- `textbook_units`: 단원, 차시, 페이지, 성취기준 연결
- `school_schedules`: 시험일, 시험 범위, 학교 진도
- `student_mastery`: 개념별 이해도, 오개념, 마지막 확인일
- `learning_plans`: 목표일, 주당 가능 시간, 계획 버전
- `plan_items`: 교과서 범위, 학습 유형, 예상 시간, 상태, 재배치 사유
- `question_events`: 사진 질문, 학생 풀이, AI 피드백, 연결된 교과서 범위

## 학습계획 생성 규칙

- 학교 진도 50%, 학생 취약 개념 30%, 누적 복습 20%를 기본 비중으로 사용한다.
- 시험 4주 전부터 시험 범위 커버리지를 우선한다.
- 하루 학습은 15~30분 단위로 나누며 한 세션에 새 개념을 두 개 이상 넣지 않는다.
- 미완료 항목은 다음 날로 단순 이동하지 않고 선행 관계와 남은 시험일까지 고려해 재배치한다.
- 질문에서 발견한 오개념은 1일, 3일, 7일 간격의 확인 문제로 계획에 삽입한다.
- 학교 진도가 변경되면 미래 계획만 다시 계산하고 완료 기록은 유지한다.

## AI 검색·응답 구조

```text
학생 질문 또는 문제 사진
→ OCR 및 교과서 페이지 후보 탐색
→ 학교 지정 교과서·현재 단원으로 후보 제한
→ 허가된 교과서 콘텐츠에서 관련 개념·예제 검색
→ 학생 이해도와 최근 오답 결합
→ 한 단계 힌트 생성
→ 결과를 질문 이벤트와 학습계획에 반영
```

AI는 검색된 교과서 근거에 출판사·단원·페이지 메타데이터를 함께 보관한다. 학생 화면에는 필요한 경우 `내 교과서 p.54 개념`처럼 출처를 표시하되, 교과서 전문을 답변에 그대로 재현하지 않는다.

## 권리 및 보안 원칙

- 교과서 전문 저장·검색·전송은 출판사 또는 권리자로부터 확보한 이용허락 범위에서만 제공한다.
- 계약 전 MVP는 국가 교육과정·성취기준, 자체 제작 설명과 문제, 학생이 질문을 위해 제공한 필요한 범위의 이미지로 제한한다.
- 학교 연결만으로 상업 서비스가 해당 교과서 전문을 이용할 권리가 생긴다고 간주하지 않는다.
- 교과서 원문 저장소와 학생 학습 데이터 저장소를 분리한다.
- AI에는 질문 해결에 필요한 최소 범위만 전달하고 API 키는 서버에서만 사용한다.

## 단계별 출시

### 1단계: 계획 MVP

- 학교·학년·교과서 수동 확인
- 시험일·범위 입력
- 교육과정 및 자체 제작 콘텐츠 기반 계획
- 질문 결과를 복습 계획에 반영

### 2단계: 교과서 연동

- 출판사 1곳, 중1 수학 1종과 라이선스 계약
- 단원·페이지 검색과 근거 표시
- 표지·ISBN·페이지 인식

### 3단계: 학교 자동화

- 학교별 지정 교과서 확인 워크플로
- 가정통신문·시험 범위표 OCR
- 학사일정 동기화 및 계획 자동 재생성

## 성공 지표

- 학교·교과서 설정 완료율
- 주간 계획 시작률과 완료율
- 계획 자동 재배치 후 복귀율
- 시험 범위 커버리지
- 오개념 재발률
- 교과서 페이지 기반 질문 해결률
- 학생 1인당 주간 능동 질문 수
